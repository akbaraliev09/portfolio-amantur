# Портфолио — Амантур Акбаралиев

Сайт-портфолио на React + Vite (русский и английский языки, тёмная и светлая тема).

## Запуск
    npm install
    npm run dev

## Где что менять
- `src/content.js` — ВСЕ тексты, навыки, контакты и список проектов.
- `public/images/photo.jpg` — ваше фото (квадратное, от 400x400).
- `public/images/projects/` — скриншоты проектов (например autoparts.jpg, 16:9, до 300 КБ).
- `public/resume-ru.pdf`, `public/resume-en.pdf` — резюме; потом в `content.js` поставьте `hasResume: true`.
